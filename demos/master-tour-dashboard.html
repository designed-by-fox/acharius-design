Master Tour Dashboard

The Master Tour mobile Dashboard as it shipped, rebuilt in HTML and CSS with the same token setup I used in Figma: one primitives collection, and one collection that applies them. Switch modes below and every part of the screen follows. Tour details are sample data, and a few colors are a shade darker or lighter than the shipped app so every text pair meets WCAG AA contrast.
