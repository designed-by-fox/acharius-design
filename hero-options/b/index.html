How I work

Design systems that scale

Master Tour had no design system when I joined. I built one from scratch using Figma variables and tokens, so switching modes (phone or tablet, light or dark, scaled font sizes) happens in two clicks inside Figma.

Empathy first

Regularly connecting with users to hear feedback and test new ideas through prototyping creates a necessary feedback loop for good design.

Accessibility as a habit

I've run manual accessibility testing, trained development and product teams, and mentored designers on WCAG. This site is built to WCAG 2.2 AA.

AI-enabled workflows

I build custom Claude Skills that audit design token usage, and I set up Figma's MCP integration so Claude can read the design system directly. I rebuilt this site with Claude Code. I routinely test new AI tools and workflows.
